# DukkanOS Mobile App - Setup and Run Guide

This directory contains documentation and configurations for running the DukkanOS mobile app locally, with Android Studio, and via Docker.

## Quick Start

| Platform | Command |
|----------|---------|
| **Web** | `npm run web` |
| **Android** | `npm run android` |
| **iOS** | `npm run ios` |
| **Development server** | `npm run dev` |

## Contents

- [Local Development](LOCAL_DEVELOPMENT.md) - Running the app locally with Expo
- [Android Studio](ANDROID_STUDIO.md) - Building and running in Android Studio
- [Docker](DOCKER.md) - Running the app via Docker (Expo development container)
- [Troubleshooting](TROUBLESHOOTING.md) - Common issues and fixes

## Prerequisites

- Node.js >= 20
- npm >= 10 or yarn >= 1.22
- Java Development Kit (JDK) 17+
- Android Studio (latest version)
- Docker Desktop (optional, for containerized development)
- Xcode (for iOS development, macOS only)
